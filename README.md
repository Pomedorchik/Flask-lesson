# Flask Auth — учебный проект «Авторизация во Flask»

Небольшое Flask-приложение с формой входа, проверкой логина/пароля на сервере
и страницей успешной авторизации.

## Тестовые учётные данные

| Логин | Пароль   |
|-------|----------|
| admin | admin123 |

> Данные хранятся в словаре `USERS` открытым текстом **исключительно для учебного примера**.
> В реальном приложении пароли хранят только в виде хешей (например,
> `werkzeug.security.generate_password_hash()` и `check_password_hash()`), а не в открытом виде.

## Структура проекта

```
flask_auth/
├── app.py              # логика приложения: роуты "/", "/login", "/welcome"
├── requirements.txt    # зависимости проекта
├── README.md           # этот файл
├── defense_guide.md    # материал для защиты проекта
└── templates/
    ├── index.html      # форма авторизации + блок ошибок
    └── login.html      # страница успешного входа
```

## Установка

Откройте терминал в папке проекта и выполните:

```bash
py -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux / macOS

# 2. Устанавливаем зависимости
py -m pip install -r requirements.txt
```

## Запуск

```bash
py app.py
```

В консоли появится адрес:

```
Running on http://127.0.0.1:5000
```

Откройте его в браузере.

## Как проверить работу

1. **Открытие главной страницы** — откройте `http://127.0.0.1:5000`, должна показаться форма «Авторизация».
2. **Пустая форма** — нажмите «Войти» с пустыми полями: браузер не отправит форму (`required`), а если отправить запрос в обход браузера, сервер вернёт «Заполните оба поля…».
3. **Неверный логин** — `user / admin123` → красное сообщение «Неверное имя пользователя или пароль».
4. **Неверный пароль** — `admin / 12345` → то же красное сообщение.
5. **Верные данные** — `admin / admin123` → переход на `/welcome` со страницей «Вы успешно авторизовались!».
6. **Возврат** — кнопка «Выйти и вернуться на главную» возвращает на форму.
7. **Перезапуск** — остановите сервер (`Ctrl+C`) и запустите `py app.py` снова: приложение работает так же.

## Возможные проблемы

| Проблема | Решение |
|----------|---------|
| `ModuleNotFoundError: No module named 'flask'` | выполните `py -m pip install -r requirements.txt` |
| Порт 5000 занят | измените запуск: `app.run(debug=True, port=5001)` |
| `jinja2.exceptions.TemplateNotFound` | проверьте, что файлы `index.html` и `login.html` лежат в папке `templates` рядом с `app.py` |

## Что улучшить в «настоящем» проекте

- хранить пароли в виде хешей (`werkzeug.security`);
- хранить пользователей в базе данных (SQLAlchemy) вместо словаря;
- запоминать вход через `session` и `flash`, защищать страницы декоратором `@login_required`;
- выключить `debug=True` при публикации.
